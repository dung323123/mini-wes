# Frontend (React + Vite)

## Setup

```bash
cd frontend
cp .env.example .env
npm install
```

## Run

```bash
npm run dev
```

Open: `http://127.0.0.1:5173`

## Build

```bash
npm run build
npm run preview
```

## API

Set API base via:
- `.env` (`VITE_API_URL`)
- hoặc chỉnh trực tiếp ô `Save API` trên UI
